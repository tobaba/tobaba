## 关于我

一个人做 Windows 桌面工具。

不用 Electron 套壳的笨重，也不想让你注册账号、绑定手机、把习惯数据交出去。
主要写 **C# / .NET + WebView2**，偏爱单文件、免安装、随时能删干净的东西。

> 如果哪个工具帮你省了每天那几次切窗口，给个 **Star** 或提个 **Issue**，都是我继续做的理由。
