## NOW

独立开发者，做 Windows 桌面工具。现在主要在做 **UCalendar**。

日程、待办、项目、黄历、便签和 AI 小秘书，收在任务栏旁边的一个面板里；16 个桌面组件会自动排成对齐的列，自定义任务栏时钟把今天放在桌面上。数据留在本机，单文件，不登录。

<p align="center">
  <img src="assets/showcase-v300.png" width="100%" alt="UCalendar 主面板：月历、日程、待办、黄历、天气">
</p>

## PRINCIPLES

- **Local first** — 数据默认在自己的磁盘上；没有账号，没有云同步。
- **Small on purpose** — 单文件 11.2 MB，双击运行，删掉 exe 即卸载。
- **Boring tech** — Tauri + Rust + React + SQLite；稳定比新潮重要。
